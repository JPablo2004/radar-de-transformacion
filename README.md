# Radar de Transformación

Panel de diagnóstico de transformación empresarial (procesos, datos, automatización e IA).

Sitio estático: `index.html`. Se despliega en Vercel sin configuración (Framework preset: **Other**).

> Nota: la generación de diagnósticos, el guardado y el chat usan funciones exclusivas de claude.ai. En esta versión estática se muestra la interfaz, pero esas funciones aparecen deshabilitadas.
